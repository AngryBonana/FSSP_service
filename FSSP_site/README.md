# Парсер судебных дел kad.arbitr.ru

Этот проект представляет собой Django-приложение для парсинга данных с сайта kad.arbitr.ru через API parser-api.com.

## Возможности

- Получение информации о судебных делах за указанный период
- Сохранение данных в базу данных Django
- Просмотр и управление данными через админ-панель Django
- Фильтрация и поиск по сохраненным делам

## Структура данных

Для каждого дела сохраняется следующая информация:
- Номер дела
- Данные об ответчике (название и адрес)
- Состояние дела
- Суд
- Тип дела
- Ссылка на карточку дела на kad.arbitr.ru

## Установка и настройка

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
cd FSSP_site
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv project
project\Scripts\activate  # для Windows
source project/bin/activate  # для Linux/Mac
```

3. Установите зависимости:
```bash
pip install django requests
```

4. Примените миграции:
```bash
python manage.py migrate
```

5. Создайте суперпользователя (если еще не создан):
```bash
python manage.py createsuperuser
```

## Настройка API

В файле `settings.py` необходимо указать следующие параметры:

```python
KAD_API_KEY = "ваш_api_ключ"  # API ключ от parser-api.com
KAD_MAX_REQUESTS = 20  # Максимальное количество запросов за один запуск
```

## Использование парсера

### Через командную строку

1. Для парсинга дел за текущую дату:
```bash
python manage.py parse_kad
```

2. Для парсинга дел за конкретную дату:
```bash
python manage.py parse_kad --date-from 2025-05-26
```

3. Для парсинга дел за период:
```bash
python manage.py parse_kad --date-from 2025-05-20 --date-to 2025-05-26
```

### Через админ-панель

1. Запустите сервер разработки:
```bash
python manage.py runserver
```

2. Откройте в браузере http://127.0.0.1:8000/admin/

3. Войдите с учетными данными суперпользователя

4. Перейдите в раздел "Cards"

В админ-панели доступны следующие возможности:
- Просмотр списка всех дел
- Фильтрация по дате создания и статусу активности
- Поиск по номеру дела, содержимому и внешнему ID
- Просмотр и редактирование деталей каждого дела

## Ограничения

- API имеет ограничение на количество запросов
- Парсер настроен на получение только базовой информации о делах
- Для каждого запуска нужно указывать количество доступных запросов в настройках

## Рекомендации по использованию

1. Начните с небольшого периода (1-2 дня) для тестирования
2. Следите за количеством оставшихся запросов к API
3. Используйте фильтры в админ-панели для удобного просмотра данных
4. Регулярно проверяйте статус активности дел

## Поддержка

При возникновении ошибок проверьте:
1. Правильность API ключа
2. Доступность сервиса parser-api.com
3. Подключение к интернету
4. Корректность формата дат (YYYY-MM-DD)
