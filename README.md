# FSSP Service

## Описание
Сервис для работы с данными kad.arbitr.r. Проект предоставляет функционал для сбора, анализа и отображения данных о юридических лицах и физических лицах из открытых источников реестар арбитражных дел.

## Основные возможности
- Регистрация и аутентификация пользователей
- Административная панель для управления данными
- Динамические карточки с информацией о компаниях
- Фильтрация и поиск данных
- Периодический сбор данных с сайта kad.arbitr.ru
- Интеграция с базой данных
- Интеллектуальный анализ данных с помощью LLM


## Технический стек
- Python 3.8+
- Django 4.2+
- Celery для фоновых задач
- Redis для кэширования и очередей
- BeautifulSoup4 для парсинга
- Docker и Docker Compose для развертывания
- LLM для анализа данных

## Требования
- Python 3.8+
- Docker и Docker Compose
- Git
- Redis (для работы Celery)

## Установка и запуск

### Вариант 1: Запуск через Docker (рекомендуется)

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd FSSP_site
```

2. Запустите приложение с помощью Docker Compose:
```bash
docker-compose up --build
```

Приложение будет доступно по адресу: http://localhost:8000

### Вариант 2: Локальная установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Примените миграции:
```bash
python manage.py migrate
```

4. Запустите Redis (необходим для работы Celery)

5. Запустите Celery worker:
```bash
celery -A FSSP_site worker -l info
```

6. Запустите сервер разработки:
```bash
python manage.py runserver
```

## Административная панель

Для доступа к административной панели перейдите по адресу: http://localhost:8000/admin

В административной панели доступны следующие функции:
- Управление пользователями
- Настройка фильтров для карточек
- Управление данными о компаниях
- Мониторинг задач Celery

## Разработка

### Создание миграций
```bash
python manage.py makemigrations
python manage.py migrate
```

### Запуск тестов
```bash
python manage.py test
```

### Запуск Celery задач
```bash
celery -A FSSP_site worker -l info
celery -A FSSP_site beat -l info
```

## Особенности реализации
- Использование Django ORM для работы с базой данных
- Асинхронные задачи через Celery
- Периодический сбор данных через Celery Beat
- Кэширование через Redis
- Docker-контейнеризация для упрощения развертывания
- Интеграция с LLM для обработки информации
